# Primer_parcial_Prog_AV
Primer parcial Merino-Roges

-- Sistema de Gestión de Garage --

Proyecto correspondiente al Parcial 1 de Programación Avanzada.

-- Descripción -- 

Sistema de consola desarrollado en Java para gestionar el ingreso, permanencia y salida de vehículos de un garage.

El sistema permite registrar vehículos, controlar la capacidad disponible, consultar los vehículos estacionados, registrar salidas y generar reportes.

-- Funcionalidades -- 
Registrar ingreso de vehículo
Registrar salida de vehículo
Listar vehículos estacionados
Mostrar estado del garage
Capacidad total
Espacio ocupado
Espacio disponible
Calcular el costo estimado según el tipo de vehículo.
